# discotheque
Indexation de ma discothèque : analyses qualité par piste (spectre, intégrité, ReplayGain 2 et true peak, DR), pages album, artiste, projet (BO, OST, comédies musicales) et compositeur, suivi des achats (Qobuz) et des nouveautés (MusicBrainz). Pages HTML statiques puis serveur local. Python, SQLite, ffmpeg.
